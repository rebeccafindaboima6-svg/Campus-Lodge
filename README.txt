CAMPUS LODGE SL WEBSITE

All project files are kept together in this one folder. There are no css, js or images subfolders.

FILES
- index.html: Home page
- about.html: About Us page
- accommodation.html: Rooms and Services page
- booking.html: Booking enquiry page
- contact.html: Contact page
- style.css: Styles and responsive layout
- main.js: Mobile navigation and demo form behaviour

IMAGES
Photographs are loaded from online image URLs in the HTML. An internet connection is needed to display these photos. No images subfolder is required in this version.

PREVIEW
Double-click index.html to open the website in Google Chrome.

UPLOAD TO GITHUB
Upload all files in this folder to the main level of your Campus-Lodge repository. Do not upload only this ZIP file; extract it first, then upload the files inside it. Keep index.html, style.css and main.js at the same level.

PUBLISH WITH GITHUB PAGES
In the repository, open Settings, then Pages. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), and save.

FORM NOTE
The booking and contact forms display a confirmation message in the browser. They do not send or store form submissions until a form service or backend is connected.
